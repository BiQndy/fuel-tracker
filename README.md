# Fuel Route Tracker ⛽

Минималистичное веб-приложение для расчёта расхода топлива по маршруту в городе.

## Возможности

- 🗺️ **Интерактивная карта** на Яндекс.Картах
- 📍 **Выбор точек А и Б** — просто кликните на карте
- 🛣️ **Построение маршрута** по дорогам города
- ⛽ **Расчёт расхода топлива** на основе расстояния и расхода авто (л/100 км)
- 🎨 **Минималистичный дизайн** с тёмной темой

## Как пользоваться

1. Откройте приложение по [ссылке](https://biqndy.github.io/fuel-tracker)
2. Кликните на карте — это будет точка **А** (начало маршрута)
3. Кликните ещё раз — это будет точка **Б** (конечная точка)
4. Приложение автоматически построит маршрут и покажет расстояние
5. Укажите расход вашего автомобиля (л/100 км)
6. Получите количество необходимого топлива

## Технологии

- **Яндекс.Карты API 3.0** — карта, маршрутизация, геокодирование
- Чистый HTML + CSS + JavaScript (без фреймворков)
- GitHub Pages — хостинг

## Разработка

```bash
# Просто откройте index.html в браузере
# или запустите локальный сервер
python -m http.server 8000
```
